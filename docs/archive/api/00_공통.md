> **버전:** v1 | **최종 수정:** 2026-05-17

---

## 1. 개요

| 항목 | 내용 |
|------|------|
| Base URL | `http://api.mybutler.kr/api/v1` |
| 프로토콜 | HTTPS 필수 |
| 데이터 포맷 | JSON (파일 업로드 시 multipart/form-data) |
| 문자 인코딩 | UTF-8 |
| 인증 방식 | JWT Bearer Token |
| API 문서 | Swagger UI `/swagger-ui/index.html` |

---

## 2. 인증 방식

모든 보호된 엔드포인트는 요청 헤더에 Access Token을 포함해야 한다.

```
Authorization: Bearer {accessToken}
```

| 토큰 | 유효기간 | 설명 |
|------|---------|------|
| Access Token | 1시간 | API 요청에 사용 |
| Refresh Token | 7일 | Access Token 재발급 전용. 응답 body로 전달되며 앱 보안 저장소에 보관 |

## 3. 공통 응답 구조

### 성공 응답

```json
{
  "success": true,
  "data": { ... }
}
```

### 페이지네이션 응답 (목록 조회)

```json
{
  "success": true,
  "data": {
    "content": [ ... ],
    "page": 0,
    "size": 20,
    "totalElements": 100,
    "totalPages": 5,
    "last": false
  }
}
```

### 에러 응답

```json
{
  "success": false,
  "error": {
    "code": "AUTH_001",
    "message": "이메일 또는 비밀번호가 올바르지 않습니다."
  }
}
```

## 4. 공통 쿼리 파라미터 (목록 조회)

| 파라미터 | 타입 | 기본값 | 설명 |
|---------|------|--------|------|
| `page` | int | 0 | 페이지 번호 (0부터 시작) |
| `size` | int | 20 | 페이지 당 항목 수 (최대 50) |
| `sort` | string | — | 정렬 필드 및 방향. 예: `createdAt,desc` |

## 5. 공통 에러 코드

### 5.1 인증·권한

| 코드 | HTTP | 메시지 |
|------|------|--------|
| `AUTH_001` | 401 | 이메일 또는 비밀번호가 올바르지 않습니다. |
| `AUTH_002` | 401 | 토큰이 만료되었습니다. |
| `AUTH_003` | 401 | 유효하지 않은 토큰입니다. |
| `AUTH_004` | 401 | 토큰이 없습니다. |
| `AUTH_005` | 403 | 해당 리소스에 대한 권한이 없습니다. |
| `AUTH_006` | 401 | Refresh Token이 만료되었습니다. 다시 로그인해주세요. |

### 5.2 유효성 검사

| 코드 | HTTP | 메시지 |
|------|------|--------|
| `VALID_001` | 400 | 요청 데이터가 올바르지 않습니다. |
| `VALID_002` | 400 | 필수 항목이 누락되었습니다: {field} |
| `VALID_003` | 409 | 이미 사용 중인 이메일입니다. |
| `VALID_004` | 409 | 이미 사용 중인 아이디(닉네임)입니다. |

### 5.3 리소스

| 코드 | HTTP | 메시지 |
|------|------|--------|
| `NOT_FOUND_001` | 404 | 요청한 리소스를 찾을 수 없습니다. |

### 5.4 파일

| 코드 | HTTP | 메시지 |
|------|------|--------|
| `FILE_001` | 400 | 지원하지 않는 파일 형식입니다. (허용: jpg, jpeg, png, webp) |
| `FILE_002` | 413 | 파일 크기가 초과되었습니다. (최대 10MB) |
| `FILE_003` | 500 | 파일 저장에 실패했습니다. |

### 5.5 서버

| 코드 | HTTP | 메시지 |
|------|------|--------|
| `SERVER_001` | 500 | 서버 내부 오류가 발생했습니다. |
| `SERVER_002` | 503 | 현재 서비스를 이용할 수 없습니다. 잠시 후 다시 시도해주세요. |
